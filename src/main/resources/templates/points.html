Points Calculation

How are points calculated per match.

Group Phase (max 10 points)

      5 Points for the correct winner.
      3 Points for the correct goal difference.
      1 Points for the number of goals for team 1.
      1 Points for the number of goals for team 2.

KO Phase (max 20 points)

      10 Points for the correct winner.
      6 Points for the correct goal difference.
      2 Points for the number of goals for team 1.
      2 Points for the number of goals for team 2.

Final (max 50 points)

      25 Points for the correct winner.
      15 Points for the correct goal difference.
      5 Points for the number of goals for team 1.
      5 Points for the number of goals for team 2.

Penalty don't count towards the final result.
